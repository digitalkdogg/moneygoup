MoneyGoUp Web Application Overview

This document provides a general overview of the MoneyGoUp web application, detailing its purpose, core features, underlying architecture, and key operational workflows.

1. Introduction

MoneyGoUp is a sophisticated platform that aims to empower investors by providing cutting-edge tools for market analysis and predictive insights. It combines traditional financial metrics with advanced machine learning and natural language processing to identify market opportunities that might otherwise be overlooked.

2. Core Modules & Features

2.1 AI-Powered Discovery (DeepMoney)

The DeepMoney engine is the heart of MoneyGoUp's discovery capabilities, identifying trending stocks and ETFs. It operates in two main versions:

DeepMoney v2.3 (Next-Gen)

  • Recursive News Discovery: Scrapes global financial RSS feeds and scans for co-mentioned peers.
  • Macro Tailwind Scoring: Integrates World Bank FDI and Trade indicators to validate thematic strength.
  • ML Validation Gate: Every candidate must pass a 1-month growth prediction threshold (≥ 1.5%).
  • v2.3 Scoring: Uses a 100-point GPS scale with 19% weights for fundamentals and ML upside.

2.2 Recommendation Engine

Direct signals surfaced on the dashboard across three categories:

  • Portfolio: AI price targets vs user cost basis.
  • Watchlist: Breakout monitoring for confirmed interests.
  • Discovery: High-GPS opportunities from the daily sync cycle.

2.3 Hot ETF Discovery Module

Identifies trending ETFs under $400/share with momentum and thematic alignment.

  • Thematic Mapping: AI, Semis, Cloud, and Cybersecurity focused.
  • Liquidity Gates: >50k Volume and >$50M AUM.

2.4 AI Prediction Engine (v3.1)

Generates multi-horizon price targets using a 109-column feature tensor.

  • Regime Detection: GMM-based clustering using VIX and Credit Spreads.
  • Dampeners: Applies unemployment and global health risk modifiers.

2.5 GPS Signal Panel (Single-Ticker View)

When a user opens a single ticker at /search/[ticker], the application fetches a GPS score in parallel via GET /api/stock_data/[ticker]/gps. The result is displayed in a StockSignalPanel above the prediction area, showing:

  • A color-coded GPS score chip and sentiment label (Strong Buy / Buy / Hold / Weak / Avoid).
  • A source badge indicating whether the score came from the user's own prior prediction or from the DeepMoney market snapshot.
  • An as-of timestamp so users can gauge data freshness.
  • A "View breakdown" link that opens the GPS Breakdown Modal with all six component scores.
  • The top-3 GPS driver metrics ranked by their component score.
  • A "Show prediction details" CTA button that triggers the embedded AI prediction workflow without the user navigating away.

The panel and the AI prediction form share a single card directly below the price history chart. The CTA wires into the prediction component via a React ref, so clicking it invokes the full MLP prediction flow inline.

2.6 User Portfolio & Watchlist

Comprehensive management of active stakes and monitored interests.

  • Real-time P&L: Based on live market quotes.
  • History: Trajectory charting for total account value.

2.7 My Portfolio Page (/portfolio)

A dedicated full-page portfolio analytics view, separate from the main dashboard. It provides performance-focused analysis tools not available on the dashboard widget view.

  • 4 KPI Stat Cards: Portfolio Value, Net Gain/Loss, CAGR (annualized), and Volatility (annualized), all computed from the portfolio's historical value series.
  • Performance Chart: The PortfolioCompareChart component (Recharts) shows the total portfolio value over 1M / 6M / 1Y / All periods. Two view modes are available: $ Absolute (raw dollar value) and % Change (indexed to 100 at period start).
  • Holdings Overlay: The sidebar lists every holding with Compare and Details buttons. Clicking Compare fetches the holding's individual value series from GET /api/user/portfolio/compare-series?ticker=X&period=Y and overlays it on the chart. Up to 4 holdings can be overlaid simultaneously.
  • Gains Breakdown Card: A donut chart (reused from the dashboard) showing unrealized gains, losses, and cost basis split.
  • Recommendations: Filtered to the portfolio and watchlist scopes only (Discovery bucket excluded) using the optional scopes prop on RecommendationsSection.

2.8 Administrative Controls & Governance

Comprehensive management of the platform's user base and system guardrails.

  • Registration Approval Flow: A multi-stage workflow ensuring all new accounts are vetted and approved by an administrator before gaining system access. After registering, new users receive an automated confirmation email (via Resend) and cannot log in until an admin approves their account.
  • Password Policy: All account creation and password reset flows require a minimum of 8 characters with at least one digit. This is enforced in the Zod validation schemas on the server (POST /api/auth/register, POST /api/auth/reset-password) and mirrored by client-side pre-submit checks on both the Register and Reset Password pages.
  • Role-Based Quotas: Enforces strict limits on watchlist size, portfolio positions, and daily lookups based on the user's tier (User, Superuser, Admin).
  • Admin Console: A centralized dashboard for user management, role promotion, and approval auditing.

3. System Architecture

MoneyGoUp employs a modern, hybrid architecture:

  • Frontend: Next.js (React/TypeScript).
  • Backend: Node.js API routes with Python ML spawning.
  • Database: MySQL (User data, History, AI results).

4. Data Synchronization

Executed via scripts/deepmoney_sync.py and scripts/get_macro_data.py:

  1. Fetch World Bank Macro context.
  2. Trigger internal Discovery API with ?refresh=true.
  3. Commit enriched results to recommended_stocks and hot_etfs.
Internal URL hardcoding: All scripts use INTERNAL_API_URL = 'http://localhost:3001' (hardcoded, not read from env) to call the Next.js API directly, bypassing nginx and its 60-second proxy timeout. The DeepMoney discovery route can take over 2 minutes to complete.

5. API Endpoints Summary

  • /api/stock_data/[ticker]: Consolidated stock details (quote, news, history, analyst, earnings, indicators).
  • /api/stock_data/[ticker]/gps: GPS score lookup for a ticker; session-aware with three-tier fallback. Always returns HTTP 200.
  • /api/prediction/[ticker]: AI forecast workflow (MLP neural network, multi-horizon price targets).
  • /api/worldbank: Consolidated macro indicators.
  • /api/dashboard: Personalized user aggregation.
  • /api/dashboard/recommendations: BUY/SELL signal generation across three buckets. The RecommendationsSection component accepts an optional scopes prop to filter which buckets are rendered.
  • /api/user/portfolio/compare-series?ticker=X&period=Y: Returns {date, value}[] for a specific holding's value over time, used by the My Portfolio overlay chart.
  • /api/prediction/deepmoney: DeepMoney discovery engine (growth stocks, hot ETFs).
  • /api/auth/forgot-password: Initiates the password reset email flow.
  • /api/auth/reset-password: Validates (GET) and consumes (POST) password reset tokens.
