MoneyGoUp Web Application Overview

This document provides a general overview of the MoneyGoUp web application, detailing its purpose, core features, underlying architecture, and key operational workflows. MoneyGoUp is an intelligent financial analysis platform designed to help users discover hot stocks and ETFs, track their portfolios, and leverage AI-powered predictions for informed decision-making.

1. Introduction: What is MoneyGoUp?

MoneyGoUp is a sophisticated platform that aims to empower investors by providing cutting-edge tools for market analysis and predictive insights. It combines traditional financial metrics with advanced machine learning and natural language processing to identify market opportunities that might otherwise be overlooked. The application focuses on surfacing high-potential growth stocks and ETFs, particularly within the fast-evolving AI and technology sectors, while also offering robust portfolio management features.

2. Core Modules & Features

MoneyGoUp is built around several interconnected modules, each contributing to its comprehensive analytical capabilities:

2.1 AI-Powered Stock & ETF Discovery (DeepMoney Engine)

The DeepMoney engine is the heart of MoneyGoUp's discovery capabilities, identifying trending stocks and ETFs. It operates in two main versions:

DeepMoney V2.1 (Next-Generation Discovery)

This advanced engine uses a multi-stage process for high-precision stock and ETF discovery:

  • Recursive News Discovery: Scrapes numerous global financial RSS feeds to find trending tickers and then recursively scans company-specific feeds for co-mentioned peers.
  • Social Sentiment Pre-Filter: Filters tickers based on social media mentions (e.g., from ApeWisdom) to reduce noise.
  • Technical Validation (Gate 1): Requires candidates to have a non-negative tradingSignalScore derived from technical indicators (SMA, RSI, Volume).
  • Sequential ML Validation (Gate 2): For stocks passing Gate 1, a 5-year data payload is used to run a 1-month ML prediction; only stocks with a predicted growth of ≥ 0.1% are considered.
  • Hot ETF Discovery (Parallel): Executes in parallel, scanning thematic watchlists and dynamic screeners for ETFs under $400 with high volume and AUM.
  • DB-Ready Enrichment: Results are enriched with sector information, GPS scores, and ML trajectories for database persistence.

DeepMoney V1 (Legacy Engine)

The original engine follows a four-stage process:

  1. News Aggregation & Sentiment Analysis: Fetches headlines from major indices, uses NLP to extract organizations, performs sentiment analysis, and resolves tickers. It also identifies AI sub-sector keywords.
  2. Dynamic Screener Discovery: Queries Yahoo Finance screeners for growth and undervalued stocks, filtering by market cap.
  3. Enrichment & Scoring (GPS): Combines candidates from news, screeners, and watchlists. It then fetches Yahoo Finance summaries and calculates a multi-factor GPS (Growth, Performance, Sentiment) score, incorporating bonuses for AI/Tech, R&D spend, and small-cap status.
  4. Final Results Compilation: Sorts and filters the results into categories like "Hot Stocks" and "Hot Markets".

Hard Gates & Classifications

All stocks must pass hard gates:

  • Stock Price Cap: Under $150/share.
  • ETF Price Cap: Under $400/share.
  • Market Cap: Between $150M and $50B (for stocks), with specific rules for watchlist items.

Stocks are classified into "Established Growth", "Up-and-Coming Stable", or "AI/Tech Hyper-Growth" profiles.

2.2 Hot ETF Discovery Module

A new module in v2.1, it identifies trending ETFs (under $400/share) with momentum and thematic alignment.

  • Hard Gates: ETFs must be under $400/share, have average daily volume > 50,000, AUM > $50M, and are typically not leveraged.
  • Discovery Strategies:
    • News Signal Alignment: Matches ETFs to trending news signals based on their top holdings.
    • ETF Dynamic Screener: Queries Yahoo Finance ETF screeners, applying filters for price, volume, AUM, leverage, 52-week return, and expense ratio.
    • Thematic ETF Mapping: Uses a curated etf_theme_watchlist.json to identify ETFs aligned with specific AI/Tech sub-sectors.
  • ETF GPS Scoring Model: A dedicated scoring model (out of 100) based on 52-week return (30%), thematic news signal (25%), 3-month momentum (20%), liquidity (15%), and expense ratio efficiency (10%), plus various bonuses. Minimum qualifying score is 55.

2.3 AI-Powered Stock Prediction Engine

This module generates price predictions for individual stocks using a sophisticated ML model.

  • Trigger: Initiated by user request on the stock detail page.
  • Data Assembly: A Node.js backend (/api/stock_data/[ticker]/data) aggregates 5 years of historical OHLCV, macro data (VIX, 10Y Treasury, Sector ETFs), and fundamental metrics. Missing data is imputed using sector medians.
  • API Gateway & Guards: The POST /api/prediction/[ticker] endpoint enforces rate limits, data history requirements, and concurrency controls.
  • Feature Engineering: A Python script (predict_weighted_analysis.py) transforms raw data into a 73-column feature tensor, including technical indicators, NLP sentiment, cyclical encodings, and lagged features.
  • MLP Training & Monte Carlo Inference: A multi-layer perceptron (MLP) model is trained on historical sequences. Monte Carlo simulations (20 passes with Gaussian noise) are used to generate uncertainty bounds.
  • Confidence Scoring: Predictions are accompanied by a confidence score (max 100) based on model accuracy, history depth, data completeness, and analyst coverage.
  • Heuristic Weighting: The raw AI prediction is adjusted by real-time market signals (technical score, uptrend, news sentiment, RSI extremes, growth multiplier) to align with current market realities.
  • Output: Provides predicted prices and percentage changes for various horizons (1-day, 1-month, 6-month, 1-year) along with a monthly trajectory.

2.4 User Portfolio & Watchlist Management

MoneyGoUp offers comprehensive tools for users to manage their investments.

  • Watchlist Management: Users can add/remove stocks from their watchlist (/api/user/watchlist). The watchlist displays live prices, 6-month moving averages, and analyst consensus data.
  • Portfolio Tracking: Users can track their active positions (/api/user/portfolio), which includes real-time P&L calculations based on purchase price versus live market data, and analyst consensus ratings.
  • Trade Operations: Supports logging initial purchases (POST /api/user/stocks), updating shares (buying/selling more, PATCH /api/user/stocks/[id]), and selling all shares (moving position back to watchlist, PUT /api/user/stocks/[id]).
  • Portfolio History: The application calculates and displays the historical value of a user's current portfolio over time (/api/user/portfolio/historical-value), retrieving historical prices for each holding.

3. System Architecture (High-Level)

MoneyGoUp employs a modern, hybrid architecture:

  • Frontend: Built with Next.js (React/TypeScript), providing a responsive and interactive user interface.
  • Backend (API Routes): Node.js (Next.js API routes) handles most API requests, authentication, data aggregation from external sources, and orchestrates calls to the ML backend.
  • ML Backend: Python scripts (predict_weighted_analysis.py) are spawned by the Node.js backend to perform intensive machine learning tasks, including feature engineering and model inference.
  • Database: MySQL stores user data, portfolio holdings, watchlist items, historical stock prices, news, and the results of DeepMoney's stock and ETF discoveries (recommended_stocks, hot_etfs, etf_cycle_summary).

4. Key External Data Sources

MoneyGoUp currently integrates with the following external data provider:

  • Yahoo Finance: Primary and sole integrated source for real-time prices, fundamentals, screeners, RSS feeds, ETF profiles, and historical data.

5. Data Synchronization (DeepMoney Sync Workflow)

A critical background process, executed via deepmoney_sync.py (likely a cron job), ensures that the dashboard always displays fresh, relevant data:

  1. Automation Trigger: A scheduled task initiates the Python sync script, which loads necessary environment variables and database credentials.
  2. API Authorization: The script makes an internal HTTP GET request to the /api/prediction/deepmoney endpoint, using an x-api-key to bypass session requirements and rate limits, and ?refresh=true to force a new analysis cycle.
  3. Discovery & Analysis: The API endpoint (in Node.js, utilizing analyzer.ts and etfDiscovery.ts) performs the multi-pass stock and ETF discovery, ML validation, and ETF filtering as described in Section 2.1 and 2.2.
  4. Deep Enrichment: Final GPS scoring for both stocks and ETFs is performed, and data is prepared into a DB-compatible JSON payload.
  5. Persistence Layer: The deepmoney_sync.py script receives this JSON, clears existing recommended_stocks data, and then saves the new qualifying stocks to recommended_stocks and ETFs to hot_etfs. It also records aggregate statistics into etf_cycle_summary. This ensures the user dashboard is updated with the latest "Hot Stocks" and "Hot ETFs".

6. API Endpoints Summary

The application exposes various API endpoints to facilitate its functionality:

  • /api/stock_data/[ticker]: Consolidated data for a stock (real-time, historical, news, analyst, indicators).
  • /api/prediction/[ticker]: Triggers an AI prediction for a specific stock.
  • /api/prediction/deepmoney: Returns AI-generated hot stock and ETF recommendations.
  • /api/dashboard: User-specific dashboard data and insights.
  • /api/user/watchlist: Manage and retrieve user's stock watchlist.
  • /api/user/portfolio: Retrieve user's stock portfolio details.
  • /api/user/stocks: Add new stock purchases to the user's portfolio.
  • /api/user/stocks/[stock_id]: Update or sell shares from a user's portfolio.
  • /api/auth/register: User registration.
  • /api/cache-stats: Admin-only endpoint for cache monitoring.
