Button Typography

All button font sizes and weights are controlled by a 3-tier global CSS system defined in src/app/globals.css. Explicit Tailwind font-size/font-weight classes are not used on buttons — the global rules are the single source of truth.

Tier 1 — Base (button)

Applied to every <button> element by default. Sets the baseline appearance for all buttons across the app.

button { font-size: 14px; font-weight: normal; cursor: pointer; }

Used for: General-purpose action buttons that do not carry a size class.

Tier 2 — Small (button.sm)

Applied to card action buttons by adding the sm class. Renders slightly smaller text with medium weight for compact card layouts.

button.sm { font-size: 12px; font-weight: 500; }

Used for: Portfolio card and Watchlist card action buttons. ActionButton in CardActions.tsx always adds the sm class (className="... sm ..."), so all card action buttons automatically receive this tier.

Tier 3 — Extra Small (button.xs)

Applied to compact period-selector buttons by adding the xs class. Used where minimum footprint is required, such as inline chart controls.

button.xs { font-size: 11px; font-weight: normal; }

Used for: Chart period buttons (1W / 1M / 6M / 1Y) in StockChart.tsx and PortfolioHistoryChart.tsx.

Summary Table

CSS Class font-size font-weight Where Applied
button 14px normal All buttons (base default)
button.sm 12px 500 Portfolio & Watchlist card action buttons (ActionButton in CardActions.tsx)
button.xs 11px normal Chart period selectors (1W/1M/6M/1Y) in StockChart.tsx and PortfolioHistoryChart.tsx
Important: Do not add Tailwind text-* or font-* classes directly to <button> elements. The global CSS rules take precedence as the single source of truth for button typography.

Accessibility Standards

MoneyGoUp is committed to WCAG 2.1 Level AA compliance.

  • Contrast: All primary text and interactive elements maintain a minimum 4.5:1 contrast ratio.
  • Focus States: Interactive elements use a high-visibility 2px blue focus ring with offset.
  • Skip Links: A "Skip to main content" link is available for keyboard/screen reader users.
  • Semantics: Strict heading hierarchy (exactly one H1 per page) and ARIA roles for dynamic content.
