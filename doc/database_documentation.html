Database Documentation

This document provides a complete overview of the MoneyGoUp MySQL database schema, relationships, and the core business logic governing user data.

Core Business Logic

Portfolio vs. Watchlist vs. Discovery Logic

The system uses the user_stocks table to manage all stock relationships. Status is determined by a combination of is_purchased and user_confirmed:

  • Watchlist State: is_purchased = 0 AND user_confirmed = 1. The user has explicitly added this stock to their monitoring list. Shows in "My Watchlist".
  • Portfolio State: is_purchased = 1 AND user_confirmed = 1 AND shares > 0. The user owns a confirmed position.
  • Discovery State: is_purchased = 0 AND user_confirmed = 0. Stocks automatically identified by the AI engine. These generate recommendations but remain hidden from the user's primary watchlist until confirmed.

Authentication & Session Tracking

User accounts are managed in the users table. Password security uses bcrypt hashing.

  • Last Login: The last_login field is updated asynchronously every time a user successfully authenticates via the /api/auth/login process.
  • Roles: The role field (default 'user') determines access to administrative features like /api/cache-stats.

Macroeconomic Data

world_bank_macro_data

Stores annual macro series used as features for GMM regime detection.

ColumnTypeNotes
idINTPrimary Key (Auto-increment)
indicator_codeVARCHAR(50)Code for the indicator (e.g., NY.GDP.MKTP.KD.ZG).
country_codeVARCHAR(3)ISO country code (default 'USA').
yearINT(4)The year for the data point.
valueDECIMAL(15,5)The numerical value of the indicator for that year.
last_updatedTIMESTAMPTimestamp of the last update.
Key Indicators Mapped:
  • NY.GDP.MKTP.KD.ZG: GDP Growth (annual %)
  • FP.CPI.TOTL.ZG: Inflation, consumer prices (annual %)
  • NE.CON.PRVT.KD.ZG: Household consumption growth (%)
world_bank_etf_gps_factors

Stores thematic and sector-specific signals for ETF GPS scoring.

ColumnTypeNotes
idINTPrimary Key (Auto-increment)
theme_or_sectorVARCHAR(100)Thematic category (e.g., AI, Technology).
indicator_codeVARCHAR(50)Code for the indicator.
country_codeVARCHAR(3)ISO country code (default 'USA').
latest_valueDECIMAL(15,5)The latest available value for the indicator.
multiplier_effectDECIMAL(5,2)A multiplier applied to the indicator's effect on GPS score.
last_updatedTIMESTAMPTimestamp of the last update.
