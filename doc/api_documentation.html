0 Fundamentals

Auth & Rate Limits

Security Layer

Authentication is handled via NextAuth.js. Protected routes require a valid session token.

Security Policy:
  • Rate Limiting: Standard 60 req/min limit per IP for public endpoints.
  • JWT: Encrypted session cookies for user-specific data access.
  • Origin Check: Strict CORS and CSRF protection on all POST/PATCH/DELETE actions.

1 Stock Data

GET /api/stock_data/[ticker]

Core: Market Snapshot

Returns real-time price, change %, and basic company metadata.

GET /api/stock_data/[ticker]/data

Internal: Prediction Preprocessor

Assembles the complete 5-year data payload for the Prediction Engine (v3+).

Logic Flow:
  • Fetches 5 years of OHLCV data.
  • Macro + Regime: Fetches VIX, Treasury, Credit Spreads (HYG/LQD), and DXY.
  • Options: Integrates IV and Put/Call ratios.
  • Calculates dataQuality metadata.

2 Prediction Engine

POST /api/prediction/[ticker]

Process: Python Spawn (v3+ Engine)

Generates an AI price prediction using a local MLP neural network.

Logic Flow:
  • Spawns predict_weighted_analysis.py.
  • v3+ Logic: Integrates GMM-based Regime Detection and interaction terms.
  • Heuristics: Strengthened weighting for Analyst Consensus, Premium, and Technical Scores.
  • Horizons: Outputs 1-day (interpolated), 1-month, 6-month, and 1-year targets.

GET /api/prediction/deepmoney

Discovery Engine (V2.1)

Advanced stock and ETF discovery engine using multi-factor analysis and ML validation. Returns both hot stocks and hot ETFs.

Logic Flow:
  • Stock Discovery: Utilizes recursive news scraping, social sentiment pre-filtering, and technical validation.
  • Stock ML Validation: Requires a minimum threshold of >= 0.1% projected 1-month growth.
  • Hot ETF Discovery: Executes in parallel, scanning thematic watchlists and dynamic screeners for ETFs under $400 with high volume and AUM (Threshold GPS >= 55).
  • Multi-factor GPS Scoring: Ranks assets based on Growth, Performance, and Sentiment.

3 Dashboard

GET /api/dashboard

User Data Aggregator

Central hub for user-specific financial data and market overview.

Logic Flow:
  • Data Aggregation: Consolidates user portfolio, watchlist, and personalized recommendations.
  • Live Market Data: Fetches real-time indices including DJI and S&P 500.
  • Top Picks: Returns the top 5 Hot Stocks and top 3 Hot ETFs from the discovery engine.

4 User Data & Portfolio

Portfolio Management

Tracking & P&L

Manage active stock positions and track performance trajectory.

GET /api/user/portfolio

Retrieve all active positions with current P&L.

POST /api/user/stocks

Record a new stock purchase in the portfolio.

PATCH / PUT /api/user/stocks/[id]

Modify existing position details or adjust quantities.

Watchlist Monitor

Stock Monitoring

Maintain a list of stocks for active monitoring and quick access.

GET /api/user/watchlist

Fetch the user's current monitored stocks.

POST /api/user/watchlist

Add a new ticker to the monitoring list.

DELETE /api/user/watchlist/[ticker]

Remove a stock from the watchlist.

GET /api/user/portfolio/historical-value

Performance Analytics

Calculates the portfolio value trajectory over time for charting.

Logic Flow:
  • Iterates through historical position states in the database.
  • Fetches historical price data for each asset held at specific time points.
  • Aggregates total value to provide a time-series growth chart for the dashboard.
