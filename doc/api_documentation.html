API Documentation

Comprehensive overview of MoneyGoUp API endpoints, logic flows, and testing coverage.

1. Stock Data & Analysis

GET /api/stock/[ticker]

Consolidated data hub for stock analysis.

Logic Flow:
  • Validates ticker(s).
  • Parallel internal calls to /historical and /news.
  • Fetches real-time quote/metadata from Yahoo & SEC.
  • Calculates Technical Indicators (SMA, RSI, Momentum).

Associated Tests: api_stock_ticker.test.ts, technicalIndicators.test.ts

GET /api/stock/[ticker]/industry

Retrieves industry comparisons and peer performance.

Associated Tests: api_stock_ticker_industry.test.ts

GET /api/stock/[ticker]/historical/[period]

Fetches historical OHLCV data.

Logic Flow:
  • Supports periods: 1d, 5d, 1mo, 3mo, 6mo, 1y, 5y, max.
  • If source=dashboard, reads from Local DB.
  • Default: Fetches from Yahoo Finance.

GET /api/stock/[ticker]/earnings

Retrieves upcoming and historical quarterly earnings data (EPS, Revenue).

Logic Flow:
  • Calls Yahoo Finance quoteSummary with earnings module.
  • Normalizes quarterly EPS and financials into a combined timeline.

GET /api/stock/[ticker]/news

Fetches filtered news articles for specific tickers.

Logic Flow:
  • Fetches Yahoo Finance RSS feed.
  • Filters articles based on ticker and company name keywords.
  • Performs sentiment analysis on titles.

GET /api/stock/[ticker]/data

Internal: Assembles the complete 5-year data payload for the Prediction Engine.

Logic Flow:
  • Fetches 5 years of OHLCV data.
  • Fetches macro series: VIX, 10Y Treasury, and Sector ETFs.
  • Imputes missing fundamental data using sector medians.
  • Caches result for 5 minutes.

2. Prediction Engine

POST /api/stock/[ticker]/predict/tensorflow

Generates an AI price prediction using a local MLP neural network.

Logic Flow:
  • Enforces 30s rate limit per ticker.
  • Spawns predict_weighted_analysis.py.
  • Applies 50% weighted influence from technical signals.

Associated Tests: stockPrediction.test.ts, predictionQueue.test.ts

3. DeepMoney & Dashboard

GET /api/deepmoney

Premium market-wide sentiment analysis.

  • Aggregates Yahoo, MarketBeat, The Street, and Motley Fool.
  • Discovers "Hot Stocks" via GPS (Global Prediction Score).

GET /api/dashboard

User-specific performance summary and holdings signals.

Associated Tests: api_dashboard.test.ts

GET /api/dashboard/on?ticker=[TICKER]

Quick check to see if a ticker exists in user's watchlist or portfolio.

Logic Flow:
  • Queries user_stocks for specific ticker.
  • Returns boolean flags: onWatchlist, onPortfolio.

Dashboard Discovery APIs

  • GET /api/dashboard/deepmoney-picks: Latest AI-generated picks from DB.
  • GET /api/dashboard/recommended-stocks: Real-time discovery (Momentum, Breakouts).
  • GET /api/dashboard/undervalued-large-caps: Screener-based value plays.

4. User Portfolio & Watchlist

Watchlist Management

  • GET /api/user/watchlist: Fetch watchlist with 6mo MA.
  • POST /api/user/watchlist: Add ticker to watch.
  • DELETE /api/user/watchlist?stockId=[ticker]: Remove from watch.

Associated Tests: api_user_stocks.test.ts

Portfolio Tracking

  • GET /api/user/portfolio: Active positions with real-time P&L.

Associated Tests: api_user_portfolio.test.ts

Trade Operations

  • POST /api/user/stocks: Log initial purchase.
  • PATCH /api/user/stocks/[id]: Update shares (buy/sell).
  • PUT /api/user/stocks/[id]: "Sell All" (Moves position back to watchlist).

Associated Tests: api_user_stocks.test.ts

5. Authentication

POST /api/auth/register

Creates new user account.

Associated Tests: api_auth_register.test.ts
