All routes are Next.js 14 App Router Route Handlers (route.ts files). All authenticated routes validate the NextAuth JWT session. The checkOrigin() middleware is applied to most mutation endpoints. An internal bypass using the x-api-key header allows server-to-server calls.
Middleware & Shared Utilities
src/middleware.ts
NextAuth withAuth middleware. Protects all routes by default. The matcher excludes: /api/auth/*, /login, /register, /forgot-password, /reset-password, and all static assets (/_next/*, /favicon.ico, *.svg/png/jpg). Internal server-to-server requests bypass auth via an x-api-key header check.
checkOrigin() — src/utils/originCheck.ts
Validates the Origin header against NEXT_PUBLIC_NEXTAUTH_URL. Returns a 403 response if the origin does not match. Applied to nearly all POST/PATCH/PUT/DELETE endpoints.

Auth Routes
GET POST /api/auth/[...nextauth] No auth required src/app/api/auth/[...nextauth]/route.ts
Delegates all NextAuth.js routes to NextAuth(authOptions) defined in src/lib/auth.ts. Handles /api/auth/signin, /api/auth/signout, /api/auth/session, /api/auth/callback/*, and CSRF token endpoints.
Auth Strategy (src/lib/auth.ts)
CredentialsProvider. On sign-in: (1) rate-limit check via loginLimiter, (2) look up user by email, (3) bcrypt.compare password, (4) call evaluateApprovalStatus() — throws if approval_status !== 'approved'. JWT and session callbacks inject id, role, and approvalStatus into the token and session.

Stock Data Routes
GET /api/stock_data/[ticker] Auth required Rate limited src/app/api/stock_data/[ticker]/route.ts
Main stock data aggregation endpoint. Fetches from Yahoo Finance, records a lookup event in stock_lookup_events, and orchestrates parallel fetches of: historical prices, news, analyst data, and earnings. Computes technical indicators (SMA20/50, RSI14, Momentum, signal score). Uses an in-flight request deduplication Map to prevent concurrent duplicate calls for the same ticker. Supports comma-separated multi-ticker in the path param.
In-flight deduplication
A module-level inflightRequests: Map<string, Promise> stores in-progress requests. If a second request for the same ticker arrives while the first is still pending, it receives the same Promise.
