API Documentation

Comprehensive overview of MoneyGoUp API endpoints, logic flows, and internal dependencies. All potentially slow endpoints include 15m–12h caching with source: 'livedata' | 'cache' reporting.

0 Fundamentals & Auth

Authentication & Security

Security Layer

Managed via NextAuth.js. All endpoints (except public assets) are protected by src/middleware.ts.

Security Policy:
  • Session: Uses JWT strategy with configurable SESSION_MAX_AGE (default 24h).
  • Internal Bypass: Endpoints can be accessed via x-api-key matching DEEPMONEY_INTERNAL_SECRET.
  • Rate Limiting: Enforced per-IP via src/utils/rateLimiter.ts.

POST /api/auth/register

User Identity

Creates a new user account with hashed passwords using bcryptjs.

GET /api/auth/cache-stats

Admin: Diagnostics

Placeholder for cache monitoring. Currently restricted to administrative privileges (returns 403 Forbidden).

1 Stock Data

GET /api/stock_data/[ticker]

Core: Consolidated Snapshot

The primary entry point for stock details. Supports comma-separated tickers. Cached for 15 minutes.

Response addition: source: 'livedata' | 'cache' Internal Dependencies:
  • Calls /api/stock_data/[ticker]/historical/1y
  • Calls /api/stock_data/[ticker]/news
  • Calls /api/stock_data/[ticker]/analyst
  • Calls /api/stock_data/[ticker]/earnings
  • Calculates Technical Indicators locally using calculateTechnicalIndicators.

GET /api/stock_data/[ticker]/data

Internal: Prediction Preprocessor

Assembles the deep 5-year data payload required by the MLP/LSTM Python engines. Cached for 15 minutes. Supports ?refresh=true.

Response addition: source: 'livedata' | 'cache' Logic Flow:
  • Fetches 5 years of OHLCV data.
  • Macro Integration: Calls /api/worldbank (propagates refresh).
  • Options: Calls /api/stock_data/[ticker]/options.
  • Performs Sector-based Imputation for missing fundamental metrics.

Specialized Sub-Data APIs

Utility Endpoints

Granular endpoints used for targeted UI updates or internal data gathering. All support ?refresh=true.

GET .../historical/[period]

Fetches OHLCV data. Cached 15m. Returns cache_status.

GET .../news

Aggregates latest news. Cached 2h. Returns cache_status.

GET .../analyst

Returns analyst targets. Cached 6h. Returns source.

GET .../earnings

Fetches earnings surprises. Cached 12h. Returns source.

2 Market Data

GET /api/market/indices

Global Market Health

Returns current prices and daily change % for major indices (DJI, S&P 500, Nasdaq, Russell 2000, VIX).

GET /api/market/trending

Market Momentum

Identifies stocks with high volume or significant price movement.

GET /api/worldbank

Macroeconomic Indicators

Consolidated World Bank macro indicators (GDP, FDI, Trade, Tech Adoption) for USA and global peers. Cached for 6 hours. Supports ?refresh=true.

Response structure: Includes success, macro, etf_factors, risk_index, and asOf.

3 Prediction Engine

POST /api/prediction/[ticker]

Process: Python Spawn (v3.1 Engine)

Generates an AI price prediction using a local MLP neural network. Results cached for 15 minutes. Supports ?refresh=true.

Response addition: source: 'livedata' | 'cache' Logic Flow:
  • Spawns scripts/predict_weighted_analysis.py.
  • v3.1 Logic: Integrates GMM-based Market Regime Detection (109 feature tensor).
  • Persistence: Automatically triggers a call to /api/prediction/save.

POST /api/prediction/save

Persistence Layer

Saves or updates a user's prediction (1d, 1m, 6m, 1y horizons) and macro observability metadata.

GET /api/prediction/deepmoney

Discovery Engine (v2.3)

Advanced stock and ETF discovery engine. Cached 30m. Supports ?refresh=true. Uses the v2.3 GPS model (19% weighting for 5 factors).

Response structure: Includes success, timestamp, count, stocks, hot_etfs, and meta.

4 Dashboard

GET /api/dashboard

User Data Aggregator

Central hub for user-specific financial data. Aggregates portfolio summary and recent user activity.

GET /api/dashboard/deepmoney-picks

UI Data Provider

Fetches the latest AI-discovered growth stocks and hot ETFs from the recommended_stocks and hot_etfs tables.

GET /api/dashboard/recommendations

Signal Engine

Returns automated BUY/SELL signals based on 1-month predictions. Applies Unemployment Dampeners (+2.0% req. threshold on bearish signal) and Global Health Modifiers.

5 Admin & Governance

GET /api/admin/users

Admin: User Management

Lists all registered users with their roles and approval statuses. Supports filtering by status, role, and search (username).

Security: Restricted to role = 'admin'.

PATCH /api/admin/users

Admin: Governance

Updates a user's approval status (approve/reject) or promotes/demotes their role (user, superuser, admin).

Guards: Prevents demoting the last active administrator.

Limit Enforcement

System: Guardrails
