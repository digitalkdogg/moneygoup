API Documentation

Comprehensive overview of MoneyGoUp API endpoints, logic flows, and internal dependencies.

0 Fundamentals & Auth

Authentication & Security

Security Layer

Managed via NextAuth.js. All endpoints (except public assets) are protected by src/middleware.ts.

Security Policy:
  • Session: Uses JWT strategy with configurable SESSION_MAX_AGE (default 24h).
  • Internal Bypass: Endpoints can be accessed via x-api-key matching DEEPMONEY_INTERNAL_SECRET.
  • Rate Limiting: Enforced per-IP via src/utils/rateLimiter.ts.

POST /api/auth/register

User Identity

Creates a new user account with hashed passwords using bcryptjs.

GET /api/auth/cache-stats

Admin: Diagnostics

Returns memory usage and hit/miss statistics for internal server-side caches.

1 Stock Data

GET /api/stock_data/[ticker]

Core: Consolidated Snapshot

The primary entry point for stock details. Supports comma-separated tickers.

Internal Dependencies:
  • Calls /api/stock_data/[ticker]/historical/1y
  • Calls /api/stock_data/[ticker]/news
  • Calls /api/stock_data/[ticker]/analyst
  • Calls /api/stock_data/[ticker]/earnings
  • Calculates Technical Indicators locally using calculateTechnicalIndicators.

GET /api/stock_data/[ticker]/data

Internal: Prediction Preprocessor

Assembles the deep 5-year data payload required by the MLP/LSTM Python engines.

Logic Flow:
  • Fetches 5 years of OHLCV data.
  • Macro Integration: Fetches VIX, Treasury (10Y/3M), Credit Spreads (HYG/LQD), DXY, and Commodities (WTI, Copper, Wheat).
  • Options: Calls /api/stock_data/[ticker]/options.
  • Performs Sector-based Imputation for missing fundamental metrics.

Specialized Sub-Data APIs

Utility Endpoints

Granular endpoints used for targeted UI updates or internal data gathering.

GET .../historical/[period]

Fetches OHLCV data for 1d, 5d, 1mo, 6mo, 1y, 5y periods.

GET .../news

Aggregates latest news headlines and performs basic sentiment analysis.

GET .../analyst

Returns analyst price targets, recommendation trends, and ratings.

GET .../earnings

Fetches upcoming earnings dates and historical EPS/Revenue surprises.

GET .../options

Retrieves Implied Volatility (IV), IV Rank, and Put/Call ratios.

GET .../industry

Returns peer stocks within the same industry taxonomy.

3 Prediction Engine

POST /api/prediction/[ticker]

Process: Python Spawn (v3+ Engine)

Generates an AI price prediction using a local MLP neural network.

Logic Flow:
  • Spawns scripts/predict_weighted_analysis.py.
  • v3+ Logic: Integrates GMM-based Market Regime Detection.
  • Persistence: Automatically triggers a call to /api/prediction/save.

POST /api/prediction/save

Persistence Layer

Saves or updates a user's prediction for a specific stock in the user_stock_predictions table.

Payload Fields: 
{
  "ticker": "string",
  "predicted_price_1d": "number | null",
  "predicted_price_1m": "number", // Required
  "predicted_price_6m": "number | null",
  "predicted_price_1y": "number | null",
  "macro_features_used": ["string"] | null,
  "consumer_multiplier_applied": "number | null",
  "last_requested_at": "string (ISO format)",
  "user_id": "string (internal use only)"
}
Database Update: Persists the provided prediction horizons and observability data.

GET /api/prediction/deepmoney

Discovery Engine (V2.1)

Advanced stock and ETF discovery engine using multi-factor analysis and ML validation.

Cross-References:
  • Internal analyzer.ts calls /api/stock_data/[ticker]/data for each candidate.
  • Then calls /api/prediction/[ticker] to validate growth potential.

4 Dashboard

GET /api/dashboard

User Data Aggregator

Central hub for user-specific financial data. Aggregates portfolio summary and top trending picks.

GET /api/dashboard/recommendations

Signal Engine

Returns automated BUY/SELL signals based on 1-month predictions across three buckets: Portfolio, Watchlist, and Discovery. Thresholds are configurable via environment variables.

See the Recommendation Buckets Guide for detailed logic.

GET /api/dashboard/on

UX Helper

Checks if a specific ticker is already present in the user's portfolio or watchlist to toggle UI buttons.

GET /api/dashboard/analyst-ratings

Personalized Sentiment

Retrieves consolidated analyst recommendations for all symbols currently held in the user's portfolio.

GET /api/dashboard/deepmoney-picks

AI Recommendations

Returns the highest-scoring stocks from the latest scripts/deepmoney_sync.py run.
