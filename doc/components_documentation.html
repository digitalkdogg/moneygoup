Complete Component Registry

This document provides a technical overview of all components, including their props and descriptions.

Main Layouts & Logic

Dashboard src/app/components/Dashboard.tsx

The central orchestrator for the user's dashboard view. Fetches combined portfolio data, manages state for market status, and coordinates the display of summary widgets and sections.

PropTypeDescription
None-Manages internal state for portfolio, totals, ratings, market status, loading, and errors. Fetches data via fetchPortfolioData. Renders various summary cards and sections.
Stock src/app/components/Stock.tsx

The primary container for the stock detail page. Manages consolidated data fetching for a ticker (quotes, news, history, earnings, analyst data) and provides a multi-ticker comparison view.

PropTypeDescription
tickerstringThe stock symbol to display.
sourcestringOptional Data source.
companyNamestringOptional Pre-fetched company name.

MarketOverviewCard src/app/components/MarketOverviewCard.tsx

Displays a summary of major market indices (S&P 500, NASDAQ, DOW, VIX) with their current prices and daily percentage changes. Refreshes periodically.

PropTypeDescription
None-Fetches data internally from /api/market/indices.

Provides a visual breakdown of portfolio performance, including unrealized gains, losses, and cost basis using a donut chart.

PropTypeDescription

AnalystRatingsCard src/app/components/AnalystRatingsCard.tsx

Summarizes analyst sentiment for stocks (primary rating, count, score) based on provided data or by fetching from an API.

PropTypeDescription
initialDataAnalystRatingsResponse | nullOptional Pre-fetched ratings data. If provided, local fetch is skipped.
PortfolioSummary src/app/components/PortfolioSummary.tsx

Calculates and displays top-level portfolio totals: Position Value, Daily Earnings, and Lifetime Earnings. Includes a toggle for the history chart.

PropTypeDescription
portfolioPortfolioItem[]List of portfolio items used for calculations.
marketStatus'open' | 'closed'Current market trading status.
showChartbooleanControls visibility of the history chart.
onToggleChart() => voidCallback to toggle chart visibility.
SummaryCard src/app/components/SummaryCard.tsx

Generic card for single metrics with label, value, and optional status indicators.

PropTypeDescription
labelstringThe title of the metric.
valuenumber | nullThe numeric value to display.
marketStatus'open' | 'closed'Optional Display "Market Closed" if applicable.
tooltipstringOptional Warning or explanatory text.
isMissingDatabooleanOptional Flags if data is incomplete.

The unified entry point for displaying stock information. It switches rendering based on the variant prop (search-trending, deepmoney, portfolio, watchlist).

A reusable wrapper for displaying lists of cards in a grid. Manages loading, error, and empty states for sections.

PropTypeDescription

dataT[]Array of items to render as cards.
renderCard(item: T, index: number) => ReactNodeFunction to render each card from data item.
loadingbooleanOptional Loading state.
errorstring | nullOptional Error message to display.
emptyMessagestringOptional Message shown when data is empty.

A generalized, responsive table component used for displaying lists of stocks with customizable columns and formatting.

PropTypeDescription

onRowClick(symbol: string) => voidOptional Callback for row click events.
loadingbooleanOptional Loading state.
errorstring | nullOptional Error message.
emptyMessagestringOptional Message for empty data state.

A standardized error banner for API failures, featuring retry buttons and troubleshooting tips.

PropTypeDescription

onRetryStock() => voidOptional Callback to retry fetching stock data.
onRetryHistorical() => voidOptional Callback to retry fetching historical data.
selectedTickerstringOptional The ticker currently being viewed, relevant for historical retries.

Displays a list of recent news articles for a stock, including title, publication date, source, and sentiment score.
