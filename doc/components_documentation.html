src/app/components/Navigation.tsx
ClientAuth-aware
Sticky top navigation bar. Renders a desktop horizontal link row and a mobile slide-in drawer. The profile dropdown (desktop) shows user initials derived from the session name. Card System
The card system uses a discriminated-union approach. A single StockCardModel type has four variants: search-trending, deepmoney, portfolio, watchlist. All cards are routed through StockCard, which switches on card.variant.
StockCardModel (types)
src/app/components/cards/types.ts
Types
Defines the discriminated union that drives the entire card system.
type StockCardModel =
  | SearchTrendingCard  // variant: 'search-trending'
  | DeepmoneyCard       // variant: 'deepmoney'
  | PortfolioCard       // variant: 'portfolio'
  | WatchlistCard       // variant: 'watchlist'

interface CardActionHandlers {
  onBuyMore?: (card: PortfolioCard) => void
  onSell?: (card: PortfolioCard) => void
  onAddToPortfolio?: (card: WatchlistCard) => void
  onRemove?: (card: WatchlistCard) => void
}

Modals
GpsBreakdownModal
src/app/components/modals/GpsBreakdownModal.tsx
ClientModal
Full-screen overlay (GPS v3.0) that details how a stock's GPS score was calculated. Displays all 8 component scores in a list format — ML Prediction (1m), AI Confidence, Revenue Growth, Earnings Growth, Technical Signal, Analyst Upside, Analyst Consensus, and 52-Week Momentum — each shown as "X.X / MAX". The Analyst Consensus row also shows the decoded label (e.g., "Strong Buy") derived from the numeric points value. Summary footer is color-coded by score band: green (≥65), amber (45–64), red (<45). Backdrop click or the close button dismisses the modal. The ticker heading uses an inline color: '#fff' style to override a global CSS rule.
PropTypeRequired
isOpenbooleanrequired
onClose() => voidrequired
symbolstringrequired
scorenumber | nullrequired
breakdownGpsBreakdown | nullrequired
GPS v3.0 — 8 components, 100 points: mlpUpside (20), mlpConfidence (5), revenueGrowth (12), earningsGrowth (12), technicalSignal (20), analystUpside (12), analystConsensus (9), priceChange52w (10). When breakdown is null, the modal shows only the numeric score.
