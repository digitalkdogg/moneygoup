Complete Component Registry

A comprehensive technical catalog of all 37 components within the MoneyGoUp application.

Main Layouts & Logic

Dashboard src/app/components/Dashboard.tsx

The central orchestrator for the user's dashboard view. Fetches combined portfolio data, manages state for market status, and coordinates the display of summary widgets and sections.

Stock src/app/components/Stock.tsx

The primary container for the stock detail page. Manages consolidated data fetching for a ticker (quotes, news, history, earnings, analyst data) and provides a multi-ticker comparison view.

Dashboard Widgets

MarketOverviewCard src/app/components/MarketOverviewCard.tsx

Displays a summary of major market indices (S&P 500, NASDAQ, DOW, VIX) with their current prices and daily percentage changes.

GainsBreakdownCard src/app/components/GainsBreakdownCard.tsx

Provides a visual breakdown of portfolio performance, including unrealized gains, losses, and cost basis using a donut chart.

AnalystRatingsCard src/app/components/AnalystRatingsCard.tsx

Summarizes analyst sentiment for stocks currently held in the user's portfolio.

PortfolioSummary src/app/components/PortfolioSummary.tsx

Calculates and displays top-level portfolio totals: Position Value, Daily Earnings, and Lifetime Earnings. Includes a toggle for the history chart.

SummaryCard src/app/components/SummaryCard.tsx

Generic card for single metrics with label, value, and optional status indicators.

Sections & Grids

PortfolioSection src/app/components/PortfolioSection.tsx

Renders the "My Portfolio" area using a grid of cards. Handles transaction modal states.

WatchlistSection src/app/components/WatchlistSection.tsx

Manages the user's watchlist display and removal logic.

DeepMoneyPicksSection src/app/components/DeepMoneyPicksSection.tsx

The "Brain" section showing AI-suggested growth candidates and hot ETFs.

TrendingStocksGrid src/app/components/TrendingStocksGrid.tsx

Shows the top trending stocks from the last 48 hours in a responsive grid.

MajorIndicesStrip src/app/components/MajorIndicesStrip.tsx

A secondary index display strip primarily used on the search page.

SectorExplorer src/app/components/SectorExplorer.tsx

Allows users to browse stocks by industry sectors (Technology, Healthcare, etc.).

IndustryStocks src/app/components/IndustryStocks.tsx

Displays a table of active stocks within a specific industry context.

PortfolioGrid src/app/components/PortfolioGrid.tsx

A specialized grid layout for portfolio items, used in the test-cards page.

Analytics & Charts

PortfolioHistoryChart src/app/components/PortfolioHistoryChart.tsx

Visualizes the total portfolio value over time. Supports time period selection (1W, 1M, 6M, 1Y).

StockChart src/app/components/StockChart.tsx

Price history chart for individual stocks with interactive tooltips and period filtering.

StockPrediction src/app/components/StockPrediction.tsx

Displays AI-generated price targets and trajectory. Includes a confidence badge and detailed signal impact breakdown.

TechnicalIndicatorsDisplay src/app/components/TechnicalIndicatorsDisplay.tsx

Shows a comprehensive breakdown of technical signals (SMA, RSI, Momentum, Volatility) and the resulting Trading Signal.

Core UI & Navigation

Navigation src/app/components/Navigation.tsx

The main site header. Handles desktop/mobile menus, user profile dropdown, and logout logic.

Search src/app/components/Search.tsx

Global search bar with autocomplete functionality. Loads ticker list from company_tickers.json.

StockCard src/app/components/cards/StockCard.tsx

A unified card component that adapts its layout and actions based on a variant prop.

StockCardSection src/app/components/StockCardSection.tsx

A reusable wrapper for card grids that handles title, loading, error, and empty states consistently.

StockTable src/app/components/StockTable.tsx

Generalized table component for listing stocks with custom formatting per column.

ApiErrorDisplay src/app/components/ApiErrorDisplay.tsx

A standardized error banner for API failures, featuring retry buttons and troubleshooting tips.

StockNews src/app/components/StockNews.tsx

Lists recent news articles for a stock with sentiment indicators.

Internal Card Components

These components are used internally by the StockCard system to ensure UI consistency.

BaseCardShell src/app/components/cards/BaseCardShell.tsx

The shared outer container for all stock cards, managing background color, borders, and hover animations.

CardHeader src/app/components/cards/CardHeader.tsx

Unified header for cards showing ticker, name, and price change percentage.

CardMetricRow src/app/components/cards/CardMetricRow.tsx

Standardized labeled row for displaying data points inside cards.

CardActions src/app/components/cards/CardActions.tsx

The bottom action area for cards, containing context-specific buttons.

Modals

BuyMoreModal src/app/components/modals/BuyMoreModal.tsx

Form for logging additional shares purchased for an existing position. Calculates the new average price in real-time.

SellModal src/app/components/modals/SellModal.tsx

Form for logging partial or full sales of a position. Calculates realized gain/loss.

PurchaseFromWatchlistModal src/app/components/modals/PurchaseFromWatchlistModal.tsx

Form for making an initial purchase of a stock currently on the user's watchlist.
