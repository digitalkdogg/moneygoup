Complete Component Registry

This document provides a technical overview of all components, including their props and descriptions.

Main Layouts & Logic

Dashboard src/app/components/Dashboard.tsx

The central orchestrator for the user's dashboard view. Fetches combined portfolio data, manages state for market status, and coordinates the display of summary widgets and sections. Now integrates the RecommendationsSection for AI alerts.

Example usage: Used on the Dashboard route at src/app/dashboard/page.tsx, where it renders the authenticated user's main portfolio experience.

PropTypeDescription
None-Manages internal state for portfolio, totals, ratings, market status, loading, and errors. Fetches data via fetchPortfolioData. Renders various summary cards and sections.
RecommendationsSection src/app/components/RecommendationsSection.tsx

Displays AI-driven BUY/SELL alerts across three buckets: Portfolio (owned), Watchlist (user-monitored), and Discovery (AI-identified). Signals are generated based on configurable thresholds using 1-month predictions.

Example usage: Used inside Dashboard on the dashboard page to surface actionable signals for all tracked assets.

PropTypeDescription
None-Fetches data internally from /api/dashboard/recommendations.
Stock src/app/components/Stock.tsx

The primary container for the stock detail page. Manages consolidated data fetching for a ticker (quotes, news, history, earnings, analyst data) and provides a multi-ticker comparison view. In single-ticker mode, it also fetches GPS data in parallel via GET /api/stock_data/[ticker]/gps on mount, then renders StockSignalPanel and StockPrediction (embedded) together inside one shared card, placed immediately after the price history chart. The panel's "Show prediction details" CTA triggers StockPrediction's generate function through a React ref.

Example usage: Used on the stock detail route at src/app/search/[ticker]/page.tsx when a user opens a specific ticker.

PropTypeDescription
tickerstringThe stock symbol to display. Supports comma-separated values for multi-ticker comparison mode.
sourcestringOptional Data source hint.
companyNamestringOptional Pre-fetched company name used when adding to watchlist.

Single-ticker GPS state

StateTypePurpose
gpsDataGpsData | nullHolds GPS score, breakdown, source, and timestamp fetched from /api/stock_data/[ticker]/gps.
gpsLoadingbooleanTrue while the GPS fetch is in flight.
predictionLoadingbooleanMirrors StockPrediction's loading state via onLoadingChange callback; drives the CTA button's disabled state in StockSignalPanel.
predictionTriggerRefMutableRefObject<() => void>Passed to StockPrediction as triggerRef; called by the panel's "Show prediction details" button to invoke the generate flow without prop drilling.

StockSignalPanel src/app/components/StockSignalPanel.tsx

Renders the GPS + AI Prediction header inside the single-ticker view. Displays the GPS score chip (color-coded), sentiment label (Strong Buy / Buy / Hold / Weak / Avoid), source badge (Your Prediction or Market Snapshot), as-of timestamp, a "View breakdown" link that opens GpsBreakdownModal, the top-3 GPS driver metrics, and a "Show prediction details" CTA button that triggers the embedded StockPrediction generate flow via the onGeneratePrediction callback.

Also exports the GpsData interface used by Stock to type the GPS fetch result.

Example usage: Used in Stock on the single-ticker view at /search/[ticker], rendered inside the shared GPS + prediction card above StockPrediction (embedded).

PropTypeRequiredDescription
tickerstringRequiredStock symbol; used in the fallback "GPS not available" message and passed to GpsBreakdownModal.
gpsDataGpsData | nullRequiredGPS payload from /api/stock_data/[ticker]/gps. When null or score is null, renders the "not yet available" state.
gpsLoadingbooleanRequiredShows an animated loading placeholder while the GPS fetch is in flight.
onGeneratePrediction() => voidRequiredCallback fired by the "Show prediction details" CTA. In Stock this invokes predictionTriggerRef.current() which calls StockPrediction's internal generate().
predictionLoadingbooleanRequiredWhen true, disables the CTA button and shows a spinner with "Generating..." label.

StockPrediction src/app/components/StockPrediction.tsx

Triggers the AI prediction workflow and displays results (1d/1m/6m/12m price targets, 18-month SVG trajectory chart, confidence scores, metric analysis accordion) for a given stock. Supports two rendering modes controlled by the embedded prop.

Standalone mode (default, embedded=false): renders its own card wrapper, title, description, and a "Generate Prediction" button. Used in the multi-ticker comparison view.

Embedded mode (embedded=true): hides the card wrapper, title, description, and standalone generate button. Only prediction results, data-quality warnings, and errors render, separated from the panel above by a top border. The generate function is exposed to the parent via triggerRef. Used inside the shared GPS + prediction card in the single-ticker view.

Example usage: Used in Stock — in embedded mode for single-ticker and in standalone mode for each ticker in multi-ticker comparison.

PropTypeDescription
tickerstringStock symbol.
currentPricenumberCurrent market price.
peRationumberOptional Price-to-Earnings ratio.
pbRationumberOptional Price-to-Book ratio.
marketCapnumberOptional Market capitalization.
sma20numberOptional 20-day Simple Moving Average.
sma50numberOptional 50-day Simple Moving Average.
rsinumberOptional 14-day Relative Strength Index.
momentumnumberOptional 10-day price momentum.
technicalScorenumberOptional Pre-calculated technical score.
recommendationKeystring | nullAnalyst recommendation key (e.g., 'buy').
newsArticlesobject[]Optional Array of news articles for sentiment scoring.
historicalEarningsobject[]Optional Array of historical earnings data (fallback if not returned by /data endpoint).
titleLevel'h1'–'h6'Optional Heading level for the section title (default: h2).
embeddedbooleanOptional When true, hides the card wrapper, title, description, and standalone generate button. Renders only results/errors with a top border separator. Default: false.
triggerRefReact.MutableRefObject<() => void>Optional When provided, the component writes its generate() function into this ref on every render, allowing a parent (such as StockSignalPanel's CTA) to invoke prediction generation externally.
onLoadingChange(loading: boolean) => voidOptional Fires whenever the internal loading state changes. Used by Stock to mirror loading state into predictionLoading, which drives the CTA button state in StockSignalPanel.

GpsBreakdownModal src/app/components/modals/GpsBreakdownModal.tsx

A full-screen overlay that displays a detailed breakdown of a stock's GPS score. Shows all six component scores (Analyst Upside, Revenue Growth, Earnings Growth, 52-Week Price, MLP Alpha, AI Confidence) in a monospaced table, plus a color-coded "Final Outlook" footer. Clicking outside the modal or the close button dismisses it.

Example usage: Opened by StockSignalPanel when the user clicks "View breakdown" and a GPS breakdown object is available.

PropTypeDescription

onClose() => voidCallback to close the modal (called on backdrop click or X button).
symbolstringTicker symbol displayed in the modal header.
scorenumber | nullOverall GPS score (0–100).
breakdownobject | nullNamed component scores. If null, shows score-only fallback.
