DeepMoney Analysis Workflow

This workflow describes the background sync process that generates the "Hot Stocks" and "Trending AI Sectors" displayed on the user dashboard.

1 Automation Trigger

File: deepmoney_sync.py

The process starts via a scheduled task (likely cron) executing the sync script.

  • Environment: Loads DEEPMONEY_INTERNAL_SECRET and DB credentials from s.
  • Action: Initiates an outbound HTTP GET request to the V2 /api/prediction/deepmoney endpoint.
↓

2 API Authorization

File: src/app/api/prediction/deepmoney/route.ts

The API validates the internal handshake:

  • RBAC: If no user session is present, it requires an x-api-key matching the internal secret.
  • Rate Limit Bypass: Requests with a valid internal API key bypass standard rate limits.
  • Force Refresh: The sync script appends ?refresh=true to ignore the 30-minute cache and trigger a fresh analysis.
↓

3Discovery & Analysis

File: src/app/api/prediction/deepmoney/route.ts
File: src/app/api/prediction/deepmoney/analyzer.ts
File: src/utils/etfDiscovery.ts

The engine uses a recursive, multi-pass discovery and validation process for both stocks and ETFs:

  • Primary Pass: Scrapes 15+ global RSS and JSON feeds (Yahoo, MarketBeat, ApeWisdom).
  • Secondary Pass: For each discovered ticker, it performs a deep-dive on that ticker's specific news feed to find co-mentioned stocks.
  • Stock ML Validation: The analyzer.ts process sequentially runs a 1-month ML prediction for each stock candidate (Threshold >= 0.1%).
  • Hot ETF Discovery Module: In parallel, etfDiscovery.ts scans thematic watchlists and dynamic screeners for ETFs under $400 with high volume and AUM (Threshold GPS >= 55).
↓

4 Deep Enrichment Stage

File: src/app/api/prediction/deepmoney/analyzer.ts
File: src/utils/etfDiscovery.ts

Final enrichment and scoring phase for all candidates:

  • Stock GPS Scoring: Based on analyst upside, revenue growth, and momentum.
  • ETF GPS Scoring: Based on 52-week return, news signal alignment, momentum, and expense ratio.
  • DB-Ready Payload: Prepares final JSON objects compatible with recommended_stocks and hot_etfs schemas.
↓

5 Persistence Layer

File: deepmoney_sync.py

The sync script receives the final enriched JSON and commits it to the database:

  • Atomic Refresh: Clears existing recommended_stocks.
  • Deep Persistence: Saves stocks to recommended_stocks and ETFs to hot_etfs.
  • Cycle Summary: Records aggregate statistics into etf_cycle_summary.
  • Result: The User Dashboard now shows new Hot Stocks and Hot ETFs.
