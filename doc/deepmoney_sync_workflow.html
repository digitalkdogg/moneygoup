DeepMoney Analysis Workflow (v2.3)

This workflow describes the multi-stage background process that updates the AI recommendations, ETF scoring, and global risk indices displayed on the dashboard.

1 Macro Data Sync

File: scripts/get_macro_data.py

The foundation of the daily sync. Fetches high-fidelity macroeconomic indicators directly from the World Bank API.

  • Indicators: GDP Growth, Inflation, FDI, Trade Volume, and Tech Adoption (Internet/ICT).
  • Countries: USA, GBR, CHN, IND, DEU.
  • Output: Populates world_bank_macro_data and triggers a macro_context_snapshots entry to freeze the day's "Global Health Score".
↓

2 DeepMoney Discovery Trigger

File: scripts/deepmoney_sync.py

Initiates the core stock and ETF discovery cycle by calling the internal API.

  • Authorization: Uses DEEPMONEY_INTERNAL_SECRET via x-api-key.
  • Internal URL: All calls use INTERNAL_API_URL = 'http://localhost:3001' (hardcoded, not read from NEXTAUTH_URL). This bypasses nginx and its 60-second proxy timeout, which the long-running DeepMoney discovery route would otherwise exceed (runtime can exceed 2 minutes). The predict_weighted_analysis.py script uses the same approach.
  • Parallel Discovery:
    • Stocks: Recursive news discovery + co-mention analysis.
    • ETFs: Thematic mapping + Macro Tailwind scoring (FDI/Trade signals).
Maintenance note: If the Next.js server port ever changes from 3001, INTERNAL_API_URL must be updated manually in each Python script — it is not controlled by environment variables.
↓

3 ML Validation Gate

File: src/app/api/prediction/deepmoney/analyzer.ts

Every stock candidate must pass a sequence-based ML validation.

  • Gate: Sequential 1-month ML prediction (Threshold ≥ 1.5% expected growth).
  • Macro Filter: Candidates are adjusted by the current market regime and World Bank consumption multipliers.
↓

4 Persistence Layer

File: scripts/deepmoney_sync.py

Commits validated findings to the database to update the dashboard.

  • Recommended Stocks: Clears existing entries and writes new top-GPS candidates.
  • Hot ETFs: Upserts discoveries into hot_etfs with macro tailwind scores.
  • Global Predictions: Synchronizes unconfirmed user_stocks for active users to surface in Discovery recommendations.

5 API Structure

Endpoint: GET /api/prediction/deepmoney

Returns a JSON payload with source: 'livedata' or source: 'cache' indicator.

{
  "success": true,
  "timestamp": "2026-04-16T...",
  "source": "cache",
  "stocks": [ ... ],
  "hot_etfs": [ ... ],
  "macro_context": {
    "global_health": 74.2,
    "unemployment_signal": "bullish"
  }
}
