DeepMoney Analysis Workflow (v2.4)

scripts/deepmoney_sync.py scripts/get_macro_data.py src/app/api/prediction/deepmoney/ Updated 2026-05-28

The DeepMoney sync is a background batch process (typically run as a cron job) that discovers, validates, and persists AI-curated stock recommendations and ETF picks to the database. The results power the dashboard's "AI Picks" panel, the discovery recommendations feed, and the macro context snapshot visible to all approved users.

v2.4 changes (2026-05-28): Added volatility-adjusted confidence gate (blocks high-beta stocks with insufficient confidence score) and ATH proximity warning flag (⚠️ATH label applied when hi_ratio > 0.97 and beta > 2.0).

1 Macro Data Sync

scripts/get_macro_data.py

The foundation of the daily sync. Fetches high-fidelity macroeconomic indicators directly from the World Bank API.

  • Indicators: GDP Growth, Inflation, FDI, Trade Volume, and Tech Adoption (Internet/ICT).
  • Countries: USA, GBR, CHN, IND, DEU.
  • Output: Populates world_bank_macro_data and triggers a macro_context_snapshots entry to freeze the day's "Global Health Score".

The sync also calls GET /api/worldbank via the internal URL to warm the World Bank cache before the discovery run begins. The response is persisted to macro_context_snapshots with today's date as the key (upsert on duplicate).

2 DeepMoney Discovery Trigger

scripts/deepmoney_sync.py — sync_deepmoney()

Initiates the core stock discovery cycle by calling the internal API endpoint.

  • Authorization: Uses DEEPMONEY_INTERNAL_SECRET via the x-api-key header. The secret is stripped of surrounding quotes before use to handle environment variable formatting quirks.
  • Internal URL: All calls use INTERNAL_API_URL = 'http://localhost:3001' (hardcoded). This bypasses nginx and its 60-second proxy timeout — the discovery route can take over 2 minutes.
  • Endpoint called: GET /api/prediction/deepmoney?refresh=true
  • Discovery methods: Recursive news discovery + co-mention analysis for stocks; thematic mapping + macro tailwind scoring for ETFs.
Maintenance note: If the Next.js server port ever changes from 3001, INTERNAL_API_URL must be updated manually in each Python script — it is not controlled by environment variables.

The response includes a meta.debug object logged during the sync showing pipeline stage counts: stocks rejected by enrichment, by signal score, by insufficient history, passed to the AI analyzer, rejected by the AI (<1.5% prediction), and final filtered count.

↓
Gate 2: Volatility-Adjusted Confidence new

Volatility-Adjusted Confidence Gate new

After passing the GPS gate, each stock is evaluated against a confidence threshold that scales with market volatility (beta):

conf_score = pred_input.get('confidence_score') or pred_input.get('confidence_score_1m') or 0
beta_val = s.get('beta') or 1.0

volatility_gate = conf_score >= 50
if beta_val > 2.5:
    volatility_gate = conf_score >= 65

if not volatility_gate:
    print(f"  [vol-gate] SKIP {ticker}: CS {conf_score} insufficient for beta {beta_val:.2f}")
    continue

Rationale: high-beta stocks amplify both upside and downside. The model's confidence score already reflects data quality and historical accuracy, but a confidence of, say, 52 on a stock with beta 3.5 represents a riskier recommendation than the same score on a beta-1.0 stock. This gate enforces a higher evidentiary bar for volatile names before they appear in the dashboard's AI Picks.

Beta rangeMinimum confidence score
beta ≤ 2.550
beta > 2.565

ATH Proximity Warning Flag new

Stocks that pass all gates but are near their 52-week high with elevated beta receive a warning appended to the metric_label stored in recommended_stocks:

hi_ratio = s.get('hiRatio52w') or 0
if hi_ratio > 0.97 and beta_val > 2.0:
    print(f"  [ath-warn] {ticker}: Near ATH ({hi_ratio:.2%}) with high beta ({beta_val:.2f})")
    metric_lbl = f"{metric_lbl} ⚠️ATH" if metric_lbl else "⚠️ATH"

The ⚠️ATH label is visible in the admin dashboard view and any UI component that renders metric_label. It does not cause the stock to be filtered out — it is informational only, surfacing the same mean-reversion risk that the High-Beta Penalty in the prediction model already penalizes in the price target itself.

Conditions: hiRatio52w > 0.97 (price is within 3% of the 52-week high) AND beta > 2.0.

4 Dashboard Qualification

deepmoney_sync.py — GPS > DEEPMONEY_RECOMMENDATION_GPS_VALUE

Stocks that passed the ML gate are then evaluated against a second, stricter threshold for inclusion in individual user dashboards:

  • GPS threshold: gps > DEEPMONEY_RECOMMENDATION_GPS_VALUE (env, default 25.0)
  • Prediction gate: predicted_change_pct ≥ 1.5%

Stocks meeting both conditions are upserted into stock_gps_scores (only if the GPS score changed by at least 0.1 points), added to user_stock_predictions for all currently approved users, and added to user_stocks as unconfirmed discovery entries (overwriting only if not already a purchased position).

The list of approved user IDs is fetched once at the start of the sync via a single SELECT id FROM users WHERE approval_status = 'approved' query.

5 Persistence & Stale Entry Cleanup

deepmoney_sync.py — post-sync cleanup

After all stocks are processed, stale discovery entries from previous runs are removed. The approach is exact: only stocks that did not qualify in today's run (i.e., not in qualifying_stock_ids) and are still marked as active unconfirmed discoveries are removed from user_stocks and user_stock_predictions.

This post-sync cleanup replaced an earlier pre-clear approach and is safe for concurrent runs because it only touches is_active = 1 AND user_confirmed = 0 rows — confirmed (user-purchased) positions are never removed.

Macro context is persisted via an upsert to macro_context_snapshots at the start of the sync when World Bank data is available.

6 API Structure

GET /api/prediction/deepmoney

Returns a JSON payload with source: 'livedata' or source: 'cache' indicator. The ?refresh=true query parameter bypasses the cache and triggers a full re-run of the discovery and AI analysis pipeline.
