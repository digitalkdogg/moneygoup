DeepMoney Analysis Workflow

This workflow describes the background sync process that generates the "Hot Stocks" and "Trending AI Sectors" displayed on the user dashboard.

1 Automation Trigger

File: deepmoney_sync.py

The process starts via a scheduled task (likely cron) executing the sync script.

  • Environment: Loads DEEPMONEY_INTERNAL_SECRET and DB credentials from .env.production.
  • Action: Initiates an outbound HTTP GET request to the legacy /api/prediction/deepmoney endpoint.
↓

2 API Authorization

File: src/app/api/prediction/deepmoney/route.ts

The API validates the internal handshake:

  • RBAC: If no user session is present, it requires an x-api-key matching the internal secret.
  • Rate Limit Bypass: Requests with a valid internal API key bypass standard rate limits.
  • Force Refresh: The sync script appends ?refresh=true to ignore the 30-minute cache and trigger a fresh analysis.
↓

3 News Aggregation & NLP

File: src/app/api/prediction/deepmoney/getNews.ts
File: src/app/api/prediction/deepmoney/analysis.ts

The system aggregates and processes financial intelligence in real-time:

  • Feeds: Fetches from Yahoo Finance, MarketBeat, The Street, and Motley Fool.
  • Fast-Path Tickers: Uses explicit XML tags from MarketBeat/Fool to resolve tickers instantly.
  • NLP Path: Uses compromise (NLP) to extract organizations from Yahoo/TheStreet headlines.
  • Sentiment: Scores every headline to calculate avgSentiment per ticker and industry.
↓

4 Multi-Stage Discovery

File: src/app/api/prediction/deepmoney/analysis.ts
File: src/utils/yahooFinanceHelper.ts

The system expands its search beyond the headlines:

  • Screeners: Hits Yahoo Finance screeners for growth_technology_stocks, undervalued_growth_stocks, day_gainers, most_bought_by_hedge_funds, and most_watched_tickers.
  • Deep Scan (Pass 2): For the top-mentioned tickers, the system fetches their specific company feeds to find co-mentioned peers.
  • Discovery Sources: Tickers are tagged with their origin (e.g., screener+keyword or company_feed).
↓

5 GPS Scoring Model

File: src/app/api/prediction/deepmoney/analysis.ts
File: src/utils/technicalIndicators.ts

Every candidate is put through a rigorous weighted scoring algorithm (0-100):

Base Weights (70% Total): Analyst Upside (25%), Revenue Growth (15%), EPS Growth (10%), Momentum (10%), Mentions (5%), News Sentiment (5%).
  • Trading Signal Gate: Stocks must have a positive tradingSignalScore (> 0) based on technical indicators (SMA, RSI, Momentum) to pass. This gate is applied to all screener results.
  • Expanded Metrics: Includes P/E, P/B, Debt-to-Equity, ROE, Beta, and Dividend Yield.
  • Hard Gates: Discards stocks with price > $300 or Market Cap > $2T.
  • AI Bonus (Up to +30 pts): Extra points for High R&D spend, small-cap status, or AI-taxonomy keyword density.
  • ETF Discovery: Final "Hot Stocks" are correlated with thematic ETFs (e.g., BOTZ, SOXX).
↓

6 Deep Enrichment Stage

File: src/app/api/prediction/deepmoney/analysis.ts

The top 5-8 finalists undergo intensive data gathering to prepare for LSTM modeling:

  • Complete History: Calls /api/stock_data/[ticker]/data for 5-year OHLCV and Fundamentals.
  • Macro Integration: Injects VIX series, 10Y Treasury yields, and Sector ETF correlations.
  • Earnings Pulse: Fetches quarterly Beat/Miss history and upcoming earnings dates.
  • News Deep Dive: Aggregates ticker-specific feeds with index-level mentions for high-density sentiment signals.
↓

7 LSTM-Ready Payload

File: src/app/api/prediction/deepmoney/analysis.ts

The API assembles a specialized JSON block for the Python Prediction Engine:

"prediction_input": {
  "historicalData": [...],
  "stockMetrics": { "peRatio": 25.0, ... },
  "macroData": { "vix": [...], "treasury10y": [...] },
  "newsArticles": [{ "sentiment_score": 5, "publishedAt": "..." }],
  "historicalEarnings": [{ "epsActual": 1.2, "epsEstimate": 1.1 }],
  "technicalScore": 6,
  "dataQuality": { "historyYears": 4.8, "imputedFields": [] }
}
Advanced Caching: Macro series (VIX/TNX) are cached for 24 hours via a shared macroCache to minimize redundant external API calls.
↓

8 Persistence Layer

File: deepmoney_sync.py

The sync script receives the final enriched JSON and commits it to the database:

  • Atomic Refresh: Clears existing recommended_stocks to ensure data freshness.
  • Deep Persistence: Now saves trading_signal, trading_signal_score, and the full prediction_input JSON block.
  • Result: The User Dashboard now shows the new analysis without triggering heavy API calls.
