HIGH-PRIORITY ADDITIONS (Significant Impact Expected)
================================================================================

1. VWAP (Volume Weighted Average Price)
   - Suggested Weight: High (10-15% of prediction power)
   - Why Add It: Shows what price institutional investors are trading at.
   - How to Add:
     * Add to technical indicators calculation in pandas_ta
     * Include in feature selection (add to important_cols)
     * Let Gradient Boosting learn relationship between price and VWAP
   - What It Measures:
     * Price > VWAP = Bought by smart money (bullish)
     * Price < VWAP = Smart money selling (bearish)
   - Implementation Code Example:
     stock_data.ta.vwap(append=True)
     # Then add 'VWAP' to selected_cols list

2. FORCE INDEX (Price × Volume Momentum)
   - Suggested Weight: High (8-12% of prediction power)
   - Why Add It: Combines price direction + volume into single momentum measure.
   - How to Add:
     * stock_data.ta.fi(append=True)  # Force Index
     * Add 'FI_13' and 'FI_50' to technical_cols
     * Captures when volume confirms price moves
   - What It Measures:
     * Positive Force Index = Buyers pushing price up
     * Negative Force Index = Sellers pushing price down
     * High absolute value = Strong conviction behind move

3. ON-BALANCE VOLUME (OBV)
   - Suggested Weight: High (8-12% of prediction power)
   - Why Add It: Volume accumulation indicator - shows if volume supports trend.
   - How to Add:
     * stock_data.ta.obv(append=True)
     * Add 'OBV' to technical_cols
     * Compare OBV trend to price trend
   - What It Measures:
     * OBV rising with price = Strong bullish confirmation
     * OBV falling with price = Strong bearish confirmation
     * OBV rising while price falls = Divergence (watch for reversal)
   - Implementation:
     stock_data.ta.obv(append=True)
     selected_cols.append('OBV')

4. ADX (Average Directional Index - Trend Strength)
   - Suggested Weight: Medium-High (8-10% of prediction power)
   - Why Add It: Measures how strong the trend is (not direction, just strength).
   - How to Add:
     * stock_data.ta.adx(append=True)
     * Add 'ADX' to technical_cols
     * Use to weight other signals (strong trend vs weak trend)
   - What It Measures:
     * ADX > 25 = Strong trend (price confident direction)
     * ADX < 20 = Weak trend (consolidation/ranging market)
     * Rising ADX = Trend strengthening
     * Falling ADX = Trend weakening
   - Implementation:
     stock_data.ta.adx(append=True)
     technical_cols.append('ADX')

5. VOLUME RATE OF CHANGE (VROC)
   - Suggested Weight: Medium (6-8% of prediction power)
   - Why Add It: Shows if volume is increasing or decreasing (trend confirmation).
   - How to Add:
     * Use manual calculation: (current_volume - volume_n_days_ago) / volume_n_days_ago * 100
     * Add as new column to stock_data
     * Include in feature selection
   - What It Measures:
     * VROC > 0 = Volume increasing (more interest/conviction)
     * VROC < 0 = Volume decreasing (less interest/conviction)
     * High positive VROC = Climactic move (often followed by reversal)
   - Implementation Code:
     stock_data['VROC'] = ((stock_data['Volume'] - stock_data['Volume'].shift(10)) 
                           / stock_data['Volume'].shift(10) * 100)

6. WILLIAMS %R (Momentum Oscillator)
   - Suggested Weight: Medium (5-8% of prediction power)
   - Why Add It: Similar to Stochastic but inverted reading (alternative view).
   - How to Add:
     * stock_data.ta.willr(append=True)  # Already included! Just verify it's used
     * Already in current model, good inclusion
   - What It Measures:
     * -20 to 0 = Overbought (may pullback)
     * -50 = Neutral
     * -100 to -80 = Oversold (may bounce)
   - Already Implemented: ✓ (Check technical_cols includes 'WILLR')

7. AROON INDICATOR (Trend Identification)
   - Suggested Weight: Medium (6-8% of prediction power)
   - Why Add It: Identifies if uptrend or downtrend just started.
   - How to Add:
     * stock_data.ta.aroon(append=True)
     * Add 'AROON_UP' and 'AROON_DOWN' to technical_cols
     * Great for catching trend reversals early
   - What It Measures:
     * Aroon Up > Aroon Down = Uptrend starting
     * Aroon Down > Aroon Up = Downtrend starting
     * Crossover = Trend change signal
   - Implementation:
     stock_data.ta.aroon(append=True)
     technical_cols.extend(['AROON_UP', 'AROON_DOWN'])

8. CCI (Commodity Channel Index - Cyclical Patterns)
   - Suggested Weight: Medium (5-7% of prediction power)
   - Why Add It: Identifies cyclical/reversal patterns in price.
   - How to Add:
     * stock_data.ta.cci(append=True)
     * Add 'CCI' to technical_cols
     * Useful for mean-reversion strategies
   - What It Measures:
     * CCI > 100 = Overbought (reversal possible)
     * CCI < -100 = Oversold (reversal possible)
     * CCI near 0 = Normal conditions
   - Implementation:
     stock_data.ta.cci(append=True)

9. PRICE RATE OF CHANGE (ROC/Momentum)
   - Suggested Weight: Medium (5-7% of prediction power)
   - Why Add It: Pure momentum - how fast is price changing.
   - How to Add:
     * stock_data.ta.roc(append=True)
     * Add 'ROC_12' and 'ROC_24' to technical_cols
     * Compare short-term vs medium-term momentum
   - What It Measures:
     * ROC > 0 = Price accelerating upward
     * ROC < 0 = Price accelerating downward
     * High ROC = Momentum extreme (reversal risk)
   - Implementation:
     stock_data.ta.roc(append=True)

11. PIVOT POINTS (Support/Resistance Levels)
    - Suggested Weight: Low (2-4% of prediction power)
    - Why Add It: Machine learning learns key price levels automatically.
    - Calculation: Pivot = (H + L + C) / 3
    - When to Add: If you want explicit support/resistance learning
    - Implementation:
      stock_data['Pivot'] = (stock_data['High'] + stock_data['Low'] + 
                             stock_data['Close']) / 3

ADVANCED WEIGHTING STRATEGIES (Optional)
================================================================================

If you want EXPLICIT control over metric importance (not recommended - let
model learn), you could implement sample weighting:

MANUAL IMPORTANCE WEIGHTING METHOD:
    # Assign importance scores (0-1 scale)
    sample_weights = np.ones(len(X_train))
    
    # Boost weight on high-volume days
    volume_normalized = X_train[:, 4] / X_train[:, 4].max()
    sample_weights *= (0.5 + 0.5 * volume_normalized)
    
    # Then train with weights:
    model.fit(X_train, y_train, sample_weight=sample_weights)

RECOMMENDATION: Don't use this. Let Gradient Boosting learn optimal weights.
Manual weighting usually hurts accuracy unless you have strong domain knowledge.

================================================================================
TESTING NEW METRICS
================================================================================

When you add new metrics, track these metrics:

1. MAE (Mean Absolute Error) - Should decrease
   Current baseline: ~1.2-2.5 per stock
   Target: < 1.0 with new metrics

2. RMSE (Root Mean Squared Error) - Should decrease
   Current baseline: ~2.0-4.5 per stock
   Target: < 2.5 with new metrics

3. Prediction Range - Should narrow (more confident)
   Current: ±12-15% of current price
   Target with improvements: ±8-10% of current price

4. Fallback Rate - How often does it resort to baseline?
   Current: ~5-10% of predictions
   Target: < 2% with good metrics

5. Visual Inspection - Do predictions make intuitive sense?
   Plot actual vs predicted for 5-10 stocks
   Look for systematic bias (always too high/low)

================================================================================
WHEN NOT TO ADD A METRIC
================================================================================

DON'T add a metric if:
1. It's highly correlated with existing metrics (redundant)
2. It adds complexity without improving predictions
3. It requires external data that's not reliable/available
4. It makes the model slower without proportional accuracy gain
5. It's specific to 1 stock type but not generalizable

EXAMPLE: Don't add both RSI and Stochastic - they're too similar.
The model will just learn to use one. Add them anyway (harmless) but
don't expect accuracy boost.
