Feature Column Validator

scripts/test_feature_columns.py Python CLI Script Utility / Test Generated 2026-06-03

Overview

test_feature_columns.py is an offline CI-style validator that verifies every column in the FEATURE_COLUMNS list defined in predict_weighted_analysis.py is correctly computed by _calculate_features_internal(). It requires no API keys, no live market data, and no network access — all inputs are generated synthetically.

Added in v3.3 (2026-06-03). The script was created to provide a fast regression check after any edit to the feature engineering pipeline, especially after the 13 new columns added in v3.3 (post-earnings drift, EPS revision velocity, upgrade scores, microstructure, institution ownership, peer RS). Running it takes approximately 5–10 seconds on a standard server.

Usage

CLI — Python 3.8+
# From the project root:
python3 scripts/test_feature_columns.py

# Verbose mode — prints a row for every column, not just failures:
python3 scripts/test_feature_columns.py --verbose
python3 scripts/test_feature_columns.py -v

Exit codes:

Exit codeMeaning
0All checks passed
1One or more checks failed — error details printed to stdout

The script imports directly from predict_weighted_analysis using a sys.path.insert relative to the script directory, so it works correctly whether invoked from the project root or the scripts/ directory.

What Is Checked

For each of the 118 columns in FEATURE_COLUMNS, four checks are applied to the output DataFrame from _calculate_features_internal():

#CheckFailure condition
1ExistenceColumn is not present in the output DataFrame at all. Reports MISSING.
2NaN rateMore than 5% of values are NaN after the general fillna pass. Columns are expected to be mostly filled.
3All-zeroAll absolute values are below 1e-12 (effectively zero). This catches columns that were assigned but never populated. Columns in the ALLOW_ALL_ZERO set are excluded from this check.
4RangeAny value falls outside the defined EXPECTED_RANGES bounds for that column (e.g. RSI must be in [0, 100]). Columns without a defined range skip this check.

Additionally, a column-count check verifies that the output DataFrame has at least as many columns as there are entries in FEATURE_COLUMNS.

Functions / Methods

run_tests(verbose=False)

Main entry point. Builds synthetic data, calls _calculate_features_internal(), then runs column-level validation and spot-checks. Prints a formatted report and exits with code 0 (pass) or 1 (fail).

ParameterTypeDescription
verboseboolWhen True, prints a result row for every column instead of only failures

Returns

None — exits the process with code 0 or 1 via sys.exit()

Example

python3 scripts/test_feature_columns.py --verbose

build_mock_inputs(date_strs)

Assembles all inputs required by _calculate_features_internal() using deterministic synthetic values. The function ensures every new feature group added to FEATURE_COLUMNS has a corresponding non-trivial source value in feature_metrics so that broadcast assignments produce testable non-zero output.

ParameterTypeDescription
date_strslist[str]Business day date strings from _make_dates()

Returns

tuple — (df, stock_metrics, macro_data, feature_metrics, options_data, current_price)

_make_ohlcv(date_strs)

Generates a synthetic OHLCV DataFrame using a geometric Brownian motion process with seed 42. Daily returns are drawn from Normal(0.0004, 0.015). High and Low are computed as noisy perturbations of Open and Close. Volume is a random integer in [500K, 5M].

ParameterTypeDescription
date_strslist[str]Date strings to use as the Date column

Returns

pd.DataFrame with columns: Date, Open, High, Low, Close, Volume

_make_macro_series(date_strs, base=100.0, drift=0.0001, noise=0.008)

Generates a synthetic macro time series for a single symbol (e.g. VIX, TNX, SPY) as a list of {date, close} dicts compatible with the format expected by merge_series_by_date() in the prediction script.

ParameterTypeDescription
date_strslist[str]Date strings
basefloatStarting price level
driftfloatDaily drift (log return mean)
noisefloatDaily volatility (log return std dev)

Returns

list[dict] — each element has keys date (str) and close (float)

Dependencies

  • predict_weighted_analysis — imports FEATURE_COLUMNS and _calculate_features_internal directly
  • numpy — synthetic data generation and array operations
  • pandas — DataFrame construction and date handling
  • datetime, timedelta, date — Python standard library, for earnings date arithmetic
  • sys, os, argparse — Python standard library

All of predict_weighted_analysis's own dependencies (sklearn, etc.) are also needed at import time.

Notes

When to run this script: After any edit to FEATURE_COLUMNS, any addition/removal of feature computation logic in _calculate_features_internal(), or any change to how feature_metrics fields are mapped to DataFrame columns. The script catches regressions — columns present in FEATURE_COLUMNS that are missing, all-zero, NaN-heavy, or out of range in the output DataFrame.
Limitation: The script validates the feature engineering function in isolation using synthetic data. It does not test the full MLP training pipeline, regime detection, cache behavior, or the API route. Use it as a fast smoke test, not a full integration test. Production predictions may exhibit different value distributions than the synthetic test data.

The ALLOW_ALL_ZERO set must be kept in sync manually when new scalar-broadcast features are added to FEATURE_COLUMNS. If a newly added column legitimately produces all-zero output in synthetic data (because its source field is not wired into build_mock_inputs()), add it to both ALLOW_ALL_ZERO and verify that build_mock_inputs() provides a non-trivial test value for the corresponding feature_metrics key.
