AI Prediction Workflow & Algorithm

This master document details the end-to-end execution path and the mathematical logic behind the Stock Prediction System (v3.1).

1 User Interaction

Frontend Component: StockPrediction.tsx

Begins when a user clicks "Generate AI Prediction". Requires 45 trading days of sequence context. Supports 15m server-side caching.

↓

2 Enriched Data Assembly

Backend Utility: GET /api/stock_data/[ticker]/data

Aggregates a 5-year multi-dimensional dataset (~1,260 rows).

Historical + Options

Daily OHLCV + IV/PCR data.

World Bank Macro

Real GDP, Consumption, and Inflation indicators integrated as annual features.

Market Regime

VIX, Treasury, and DXY used for GMM clustering.

↓

3 API Gateway & Guards

Backend Handler: POST /api/prediction/[ticker]

Enforces strict reliability gates: 30s cooldown, 504-day history minimum, and concurrency semaphores.

↓

4 Feature Engine & Regime Detection

Python Engine: scripts/predict_weighted_analysis.py

Transforms raw JSON into a 109-column feature tensor:

  • Regime Selection (GMM): Identifies current market state (Risk-On, Risk-Off, etc.).
  • Macro Features: WorldBank_Real_GDP and interaction terms like Regime_x_GDP.
  • Scaling: Min-Max normalization per regime context.

Algorithm Flowchart

JSON Input → GMM Regime Detector → 109+ Feature Engineering → MLP Training (Adam Optimizer) → Dual Path Inference (Deterministic + Monte Carlo Dropout 12x) → Heuristic Weighting → JSON Output

5 MLP Training & MC Inference

Model Architecture: 256 → 128 → 64 → 32 (ReLU)

Trains a fresh model on historical sequences (SEQ_LEN=45). 12x Monte Carlo passes generate statistical spreads for confidence scoring.

6 Final Signal Weighting

Logic: Heuristic Adjustments

Neural network output is nudged by real-world signals:

  • Consumption Multiplier: Applied to consumer sectors based on World Bank consumption growth trends (+/- 3%).
  • Technical/Analyst Weights: Combined influence of +/- 12%.
  • Global Health Score: Dampens predictions if global macro indicators fall below 45/100.

7 Persistence Layer

Backend Utility: POST /api/prediction/save

Saves 1d, 1m, 6m, and 1y price targets to user_stock_predictions. Stored data includes macro_features_used for model observability.
