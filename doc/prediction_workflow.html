AI Prediction Workflow

This document details the complete end-to-end execution path when a user triggers a price prediction from the Stock Search page.

1 User Interaction

Frontend Component: StockPrediction.tsx

The workflow begins when the user clicks "Generate AI Prediction" on the stock detail page.

  • Inputs: The component already holds the technicalScore (from Technical Indicators section) and recent newsArticles.
  • State Change: UI enters fetching status, showing a progress spinner.
↓

2 Enriched Data Assembly

Backend Utility: GET /api/stock_data/[ticker]/data

Before predicting, the frontend requests a "Data Payload". This API acts as a high-speed aggregator:

  • Historical: Fetches 5 years of OHLCV data (~1,260 trading days).
  • Macro: Parallel fetch of VIX (Volatility Index) and 10Y Treasury Yields.
  • Sector: Fetches historical data for the stock's corresponding sector ETF (e.g., XLK for Tech).
  • Imputation: If fundamental metrics like PE Ratio are missing, it uses sector-median values.
Why? The AI model requires consistent, multi-dimensional data. Standardizing it in Node.js keeps the Python script focused solely on math.
↓

3 Prediction Orchestration

Backend Handler: POST /api/prediction/[ticker]

The frontend merges the assembly data with the user's real-time signals and sends it to the main prediction endpoint.

  • Rate Limiting: Checks a 30-second cooldown per User+Ticker.
  • Concurrency: Uses a Semaphore to limit active Python processes (preventing CPU spikes).
  • Bridging: Node.js writes the entire payload to a secure temp file and spawns the Python child process.
↓

4 Feature Engineering

Python Engine: predict_weighted_analysis.py

The script loads the pre-trained MLP model and transforms the raw JSON into tensors:

  • Lag Features: Creates rolling windows (t-5, t-10, t-20) for price and volume.
  • Sentiment: Aggregates sentiment scores for the last 10 news articles.
  • Normalization: Scales all features using StandardScaler to match training distributions.
↓

5 Monte Carlo Inference

Model: mlp_dual_horizon_v3.h5 (TensorFlow)

Instead of a single "guess," the model performs 50 randomized passes (MC Dropout):

  • The model predicts both 6-month and 12-month targets simultaneously.
  • Gaussian noise is added to the input sequence proportional to recent volatility.
  • Trajectory: It builds an 18-month curve by interpolating between the current price and the statistical means of the 50 MC runs.
↓

6 Signal Weighting & Final Output

Adjustment Logic: metric_analysis()

The pure AI result is "nudged" by high-level market heuristics:

  • Trend Check: Stocks in a clear uptrend receive a +2.0% bonus.
  • Technical Influence: The technicalScore (-14 to +14) is applied at a rate of 0.25% per point.
  • Impact Limit: The combined influence from technical signals is capped at +/- 3.5%.
Example: If the model predicts $100 but the Technical Signal is "Strong Buy" (+14), the final output is adjusted to $103.50.
