AI Prediction Workflow & Algorithm

This master document details the complete end-to-end execution path and the mathematical logic behind the Stock Prediction System.

1 User Interaction

Frontend Component: StockPrediction.tsx

The workflow begins when the user clicks "Generate AI Prediction" on the stock detail page.

  • Lookback: The model requires 60 trading days of context for each prediction.
  • Inputs: The UI passes the technicalScore (-14 to +14) and recent newsArticles to be used as final weights.

3 API Gateway & Guards

Backend Handler: POST /api/prediction/[ticker]

The system enforces strict reliability gates before spawning the model process:

  • Origin & Auth: Validates session and CSRF.
  • Rate Limit: 30-second cooldown per user+ticker combo.
  • Data Gate: Rejects tickers with < 504 trading days (~2 years) of history.
  • Concurrency: Uses a Semaphore to cap active Python processes.

4 Feature Engineering

Python Engine: predict_weighted_analysis.py

The script transforms raw JSON into a 63-column feature tensor using specialized preprocessing:

  • Time-Decay News: Older news articles lose weight linearly over 30 days. Final score is tanh(weighted_avg).
  • Cyclical Encoding: Months are converted to sin/cos coordinates to prevent December → January "cliffs".
  • Scaling: All features are normalized to [0, 1] using MinMaxScaler.

5 MLP Training & MC Inference

Model Architecture: 128 → 64 → 32 (ReLU)

The system trains a fresh model on the historical sequences to capture the stock's specific unique character:

  1. Train/Test Split: 80% history for training, last 20% for holdout evaluation (MAPE calculation).
  2. Dual Horizon: Model outputs two nodes: [6-month Target, 12-month Target].
  3. Monte Carlo Passes (20x): Gaussian noise (10% of recent σ) is added to the features across 20 iterations.
  4. Uncertainty Bounds: Upper/Lower bands are derived from the 10th and 90th percentile of the MC results.

6 Final Signal Weighting

Logic: metric_analysis() adjustment

The "Pure AI" result from the neural network is nudged by high-level market signals to ensure it aligns with current technical realities and user-defined indicator strength.

Final Price = AI_Output * (1.0 + Total_Impact)

This multiplier allows the model to stay grounded by short-term momentum and trend signals that may not be fully captured by historical sequences alone.

-- Heuristic Weighting Logic (Total_Impact Breakdown)

The Total_Impact is the sum of five distinct market signals. Each signal adds or subtracts a specific percentage from the base AI prediction:

1. Technical Total Score

Influence of the summed indicator values from the UI.

Score * 0.0025

Max Influence: +/- 3.5% (at +/- 14 score)

2. Uptrend Bonus

Checks if the stock is making Higher Highs and Higher Lows.

Fixed Influence: +/- 2.0%

3. News Sentiment

Decayed tanh-scaled score of recent headlines.

Sentiment * 0.01

Max Influence: +/- 1.0%

4. RSI Extremes

Punishes overbought (>75) and rewards oversold (<25).

Fixed Influence: +/- 1.0%

5. Growth Multiplier

20-day trailing mean vs. prior 20-day mean.

(Growth / 100) * 0.02

Variable Influence: Typically +/- 0.5%

Impact Classification Levels

Total_Impact Value Classification System Meaning
> +0.08 Very Bullish Strong alignment across all technicals and AI.
+0.04 to +0.08 Bullish Technical momentum supports AI prediction.
-0.04 to +0.04 Neutral AI prediction is primarily driving the result.
-0.08 to -0.04 Bearish Technicals are dampening the AI's optimism.
< -0.08 Very Bearish Strong technical headwind against AI prediction.
